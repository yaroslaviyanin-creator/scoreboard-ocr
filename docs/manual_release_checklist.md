# Manual Release Checklist

Проверить перед каждым релизом на **обеих платформах** (Windows и macOS).

## Windows

- [ ] Камеры: список в выпадающем меню не пуст, соответствует подключённым устройствам
- [ ] Камера: запуск показывает живое видео без задержек и зависаний
- [ ] ROI: добавление зоны, перемещение, ресайз за угол работают плавно
- [ ] Настройки: двойной клик по зоне — диалог открывается, смена режима и ползунков сразу отражается в debug-панели
- [ ] 4 режима (Standard / Time / Name / 7-segment): для каждого распознанное значение стабилизируется и появляется в debug-панели
- [ ] Вывод .txt: при указанной папке создаются/обновляются файлы `{имя_зоны}.txt` с корректным содержимым
- [ ] vMix / внешняя программа: читает файл без артефактов частичной записи (проверить текстовым редактором с автообновлением)
- [ ] Сохранение/загрузка пресета: воспроизводит те же зоны, настройки и шаблоны
- [ ] Закрытие: камера и OCR-поток останавливаются, процесс не висит в диспетчере задач
- [ ] Логи: `%APPDATA%/ScoreboardOCR/logs/` содержит `scoreboard_ocr.log` без `except: pass`-подобных дыр

## macOS (Apple Silicon)

- [ ] Камеры: список не пуст, соответствует подключённым устройствам
- [ ] Камера: запрос разрешения (NSCameraUsageDescription) появляется при первом запуске
- [ ] Камера: живое видео без задержек
- [ ] ROI: добавление, перемещение, ресайз работают
- [ ] Настройки: диалог, смена режимов и ползунков — отражение в debug-панели
- [ ] 4 режима: все работают, значения стабилизируются
- [ ] Вывод .txt: атомарная запись, vMix читает корректно
- [ ] Сохранение/загрузка пресета: round-trip без потерь
- [ ] Закрытие: потоки останавливаются, процесс не висит (проверить Activity Monitor)
- [ ] Логи: `~/Library/Logs/ScoreboardOCR/scoreboard_ocr.log` пишется корректно
- [ ] Tesseract: если не установлен — показана понятная ошибка, а не тихий сбой

## Сборка (.app / .exe)

- [ ] macOS: `pyinstaller build/macos.spec` собирает `.app` без ошибок
- [ ] macOS: `.app` запускается, камера запрашивает разрешение
- [ ] Windows: `pyinstaller build/windows.spec` собирает `.exe` без ошибок
- [ ] Windows: `.exe` запускается, камера работает

## Регрессия

- [ ] Старый пресет (из прототипа) загружается без ошибок
- [ ] Формат `.txt` вывода побайтово совместим с тем, что читает vMix в текущей продакшн-настройке
- [ ] `pytest` зелёный на обеих платформах
